**VEGA** — **V**isual-novel **E**ngine for **G**raphical **A**dventures

Vega는 웹과 네이티브 앱을 위한 확장형 비주얼 노벨 엔진입니다. 작품에 맞는 렌더러,
캐릭터 시스템, 테마, 리소스 공급자와 UI를 자유롭게 선택할 수 있습니다.

## 할 수 있는 일

- 대사, 선택지, 장면, 애니메이션, 오디오, 비디오와 전환 재생
- 저장, 기록, 설정과 분기 스토리
- Vue, React 및 Web Component에 임베드
- 플러그인으로 고급 렌더링, 동적 캐릭터와 맞춤 UI 추가

Vega는 독점 캐릭터 SDK나 게임 리소스를 포함하지 않습니다. 작품은 필요한 플러그인과
사용 권한을 가진 런타임만 제공합니다.

## 시작하기

[First Light](https://github.com/haneoka-gakuen/vega-example-first-light)는
편집 가능한 예제 프로젝트입니다.

```sh
pnpm install
pnpm check
```

제작과 현지화에는 [Altair](https://github.com/haneoka-gakuen/altair),
배포 빌드에는 [Deneb](https://github.com/haneoka-gakuen/deneb)을 사용합니다.

Vega는 MPL-2.0으로 배포됩니다.
