**VEGA** — **V**isual-novel **E**ngine for **G**raphical **A**dventures

Vega 是面向 Web 与原生应用的可扩展视觉小说引擎。它把剧情项目变成可交互作品，
同时允许项目自由选择渲染器、角色系统、主题、资源来源和界面。


## Vega 能做什么

- 播放台词、选项、场景、动画、音频、视频和转场。
- 提供存档、回看、设置和分支剧情。
- 嵌入网页，并支持 Vue、React 和 Web Component。
- 通过插件加入高级渲染、动态角色和自定义界面。

Vega 不附带专有角色 SDK 或游戏素材。项目只需提供自己需要且有权使用的插件与运行时。

## 开始使用

[First Light](https://github.com/haneoka-gakuen/vega-example-first-light)
是可编辑的完整示例项目。

```sh
pnpm install
pnpm check
```

使用 [Altair](https://github.com/haneoka-gakuen/altair) 创作与本地化项目，
使用 [Deneb](https://github.com/haneoka-gakuen/deneb) 构建发布版本。

Vega 以 MPL-2.0 发布。
