**VEGA** — **V**isual-novel **E**ngine for **G**raphical **A**dventures

Vega は Web とネイティブアプリ向けの拡張可能なビジュアルノベルエンジンです。
レンダラー、キャラクターシステム、テーマ、素材、UI を作品ごとに選べます。

## できること

- 台詞、選択肢、シーン、アニメーション、音声、動画、画面遷移の再生
- セーブ、履歴、設定、分岐シナリオ
- Vue、React、Web Component への組み込み
- プラグインによる高度な描画、動的キャラクター、独自 UI

Vega は専有キャラクター SDK やゲーム素材を同梱しません。作品が必要なプラグインと、
利用許諾を持つランタイムだけを提供します。

## はじめる

[First Light](https://github.com/haneoka-gakuen/vega-example-first-light)
は編集可能なサンプルプロジェクトです。

```sh
pnpm install
pnpm check
```

制作と翻訳には [Altair](https://github.com/haneoka-gakuen/altair)、
配布ビルドには [Deneb](https://github.com/haneoka-gakuen/deneb) を使用します。

Vega は MPL-2.0 で公開されています。
